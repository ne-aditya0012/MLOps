## MLOps

MLOps improves the **Machine Learning Life Cycle (MLLC)** by automating the development, deployment, monitoring, and maintenance of machine learning models.

Unlike DevOps, MLOps manages **both code and machine learning models**.

### Focus Areas

- Data Collection
- Data Validation
- Data Versioning
- Feature Engineering
- Model Training
- Hyperparameter Tuning
- Model Evaluation
- Model Versioning
- Model Registry
- Model Deployment
- Model Monitoring
- Model Retraining
- Pipeline Automation
- Experiment Tracking

---

### Typical MLOps Pipeline

```
Raw Data
    │
    ▼
Data Validation
    │
    ▼
Feature Engineering
    │
    ▼
Model Training
    │
    ▼
Model Evaluation
    │
    ▼
Model Registry
    │
    ▼
Deploy Model
    │
    ▼
Inference (Predictions)
    │
    ▼
Monitor Model Performance
    │
    ▼
Retrain with New Data
```

## Common MLOps Tools

| Purpose | Tools |
|---------|------|
| Version Control | Git, GitHub |
| Data Versioning | DVC, LakeFS |
| Experiment Tracking | MLflow, Weights & Biases |
| Model Registry | MLflow Model Registry |
| Pipeline Orchestration | Kubeflow, Apache Airflow |
| Model Serving | TensorFlow Serving, TorchServe, KServe |
| Containers | Docker |
| Orchestration | Kubernetes |
| Cloud ML Services | AWS SageMaker, Azure ML, Vertex AI |
| Monitoring | Evidently AI, Prometheus, Grafana |
