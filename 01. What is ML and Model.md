## 1 - What is Machine Learning & What is a Model?

 - Machine Learning (ML) is the process of teaching a computer to find patterns from data instead of explicitly programming every rule. 
 - A Model is the result of that learning—the mathematical function that has learned those patterns and can make predictions on new data.

```
A flower has - Petal, Stem, Sepal
Imagine that you can code a python program that answers the type of flowers based on these three inputs (x,y,z) 
for ex. 2,3,2 = rose

In this manner you'll have to write too many conditional if,if elses for 10000+ flower species!!
Also, a rose is not identical to other roses, so it adds to the iterations
```
A **dataset** is a structured collection of data used to train, validate, or test a machine learning model.

It consists of **examples (rows)** and **features (columns)**. Each row represents one observation, while each column represents a specific attribute of that observation.

#### Technical Definition

A dataset is typically represented as a matrix:

```
D = { (X₁, Y₁), (X₂, Y₂), ..., (Xₙ, Yₙ) }
```

Where:

- **X** = Input features
- **Y** = Target (label/output)
- **n** = Number of samples

The machine learning algorithm learns the relationship between **X** and **Y** using this dataset.  
  
- A Data Scientist takes a Dataset and Writes an Algorithm (Code)
- The Algorithm is then trained on the Dataset, the result of this process is a function called Model.

## 2 - How is a Model Created (by a Data Scientist)

#### Step 01
Collect and prepare the dataset.
```
- Gather data from various sources.
- Clean missing or incorrect values.
- Perform feature engineering if required.
- Split the dataset into **Training (80%)** and **Testing (20%)** sets.
  - *(Sometimes a validation set is also used, e.g., 70% / 15% / 15%.)*
```
#### Step 02
Choose a Machine Learning algorithm.
```
Examples:
- KNN (K-Nearest Neighbours)
- Decision Tree
- Random Forest
- Logistic Regression
- Support Vector Machine (SVM)
- Neural Network
```
#### Step 03
Train the model using the training dataset.

The algorithm learns patterns from the training data by adjusting its internal parameters.

#### Step 04
Evaluate the trained model using the test dataset.
```
Measure its performance using metrics such as:
- Accuracy
- Precision
- Recall
- F1 Score
- Mean Squared Error (for regression)
```
#### Step 05
Improve the model if necessary.
```
Possible improvements include:
- Training with more or better-quality data
- Performing feature engineering
- Tuning hyperparameters
- Trying a different algorithm
```
Repeat the training and evaluation process until the desired performance is achieved.

#### Step 06
Save (serialize) the trained model.
```
Common formats include:
- `.pkl` (Pickle)
- `.joblib`
- `.onnx`
```
#### Step 07
Deploy the model.
```
Deploy the model by integrating it into:
- A REST API
- A web application
- A mobile application
- A desktop application
- A cloud service
```
