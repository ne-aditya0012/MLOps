## MLOps

MLOps improves the **Machine Learning Life Cycle (MLLC)** by automating the development, deployment, monitoring, and maintenance of machine learning models.

Unlike DevOps, MLOps manages **both code and machine learning models**.

### Focus Areas

- Data Collection
- Data Validation
- Data Versioning
- Feature Engineering
- Model Training
- Hyperparameter Tuning
- Model Evaluation
- Model Versioning
- Model Registry
- Model Deployment
- Model Monitoring
- Model Retraining
- Pipeline Automation
- Experiment Tracking

---

## MLLC Machine Learning Life Cycle

The **Machine Learning Life Cycle (MLLC)** is a structured process followed to build, train, deploy, and maintain machine learning models.

---

### 1. Problem Definition

Identify the business problem and determine whether machine learning is the appropriate solution.

**Examples:**
- Predict house prices
- Detect spam emails
- Recommend products
- Predict customer churn

---

### 2. Data Collection

Gather data from various sources.

**Sources may include:**
- Databases
- CSV/Excel files
- APIs
- IoT devices
- Web scraping
- Data lakes

**Output:** Raw dataset

---

### 3. Data Preparation (Preprocessing)

Clean and prepare the data before training.

**Common tasks:**
- Handle missing values
- Remove duplicates
- Fix incorrect data
- Encode categorical values
- Scale/normalize numerical features
- Handle outliers

**Output:** Clean dataset

---

### 4. Feature Engineering

Create or select the most useful input features for the model.

**Examples:**
- Extract year from a date
- Combine multiple columns into one feature
- Select important features
- Reduce dimensionality

**Output:** Optimized feature set

---

### 5. Split the Dataset

Divide the dataset into separate sets.

A common split is:

- **Training Set:** 80%
- **Testing Set:** 20%

Sometimes a validation set is also used, for example:

- Training: 70%
- Validation: 15%
- Testing: 15%

---

### 6. Model Selection

Choose the appropriate machine learning algorithm.

**Examples:**
- Linear Regression
- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbours (KNN)
- Support Vector Machine (SVM)
- Neural Network

---

### 7. Model Training

Train the selected algorithm using the training dataset.

During training, the algorithm learns patterns and relationships from the data.

**Output:** Trained model

---

### 8. Model Evaluation

Evaluate the model using unseen test data.

**Common evaluation metrics:**

#### Classification
- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC

#### Regression
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

---

### 9. Model Improvement

Improve the model if the performance is not satisfactory.

Possible improvements include:

- Collect more data
- Improve data quality
- Perform better feature engineering
- Tune hyperparameters
- Choose a different algorithm

Repeat training and evaluation until the desired performance is achieved.

---

### 10. Model Serialization

Save the trained model for later use.

Common formats:

- `.pkl`
- `.joblib`
- `.onnx`

---

### 11. Model Deployment

Deploy the model so applications can use it.

Deployment options include:

- REST API
- Web application
- Mobile application
- Cloud service
- Edge device

---

### 12. Monitoring

Monitor the deployed model in production.

Monitor:

- Prediction accuracy
- Response time
- Resource usage
- Data drift
- Concept drift
- Model performance

---

### 13. Model Retraining

As new data becomes available or model performance degrades, retrain the model.

This ensures the model continues making accurate predictions.

# Summary

The **Machine Learning Life Cycle (MLLC)** is the end-to-end workflow for developing machine learning solutions. It starts with understanding the problem, preparing data, training and evaluating a model, deploying it to production, monitoring its performance, and continuously retraining it as new data becomes available.
